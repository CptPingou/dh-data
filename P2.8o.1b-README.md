# P2.8o.1b — Restauration sûre du bouton Chasse

P2.8o.1a supprimait le fallback `canvas.tokens.controlled[0].actor`, mais le
chooser Foundryborne 2.9.4 n'expose pas toujours son Actor. Résultat : le bouton
Chasse disparaissait.

Ce correctif :
- restaure toujours le bouton dans le chooser Foundryborne ;
- n'utilise jamais le token contrôlé pour décider du personnage ;
- utilise l'Actor du chooser lorsqu'il est réellement disponible ;
- sinon affiche un petit sélecteur explicite de personnage avant d'ouvrir le
  gestionnaire Chasse.

Cela garantit qu'une fiche `test2` ne peut plus modifier silencieusement le
loadout de `test`.

Validation :
- bouton Chasse de nouveau visible ;
- si le chooser fournit son Actor : ouverture directe ;
- sinon sélection explicite `test` / `test2` ;
- `test` => 2/2 ; `test2` => 0/2.
