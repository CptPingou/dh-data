# P2.12c — contraintes matérielles de conteneur

- `materialStorage` est optionnel sur un conteneur d'expédition.
- `accepts` filtre `flags.daggerheart-campaign-toolkit.material.containerClass`.
- `stackLimit` limite une pile matérielle lors d'une acquisition/fusion ou d'un transfert.
- Un refus ne mute pas le manifeste.
- Les conteneurs sans `materialStorage` conservent le comportement legacy.
- Aucun profil chiffré n'est encore imposé aux sacs à dos / caravane : ce sera P2.12d.
