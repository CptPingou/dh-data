# P2.8p.1b — Reaction Effect Immediate Fix

Correctif patch-only au-dessus de P2.8p.1 + P2.8p.1a.

## Correction

Les effets `monster-reaction` sont des modificateurs immédiats de la réaction
manuelle du monstre. Ils restent affichés dans le message de réaction, mais ne
sont plus ajoutés à `pendingEffects`.

Ainsi :
- Feinte d'approche → message de réaction avec −1d4, sans état pending.
- Guidage du Finisher → reste pending jusqu'au prochain Finisher.
- Frappe de rupture → reste une option de conversion et n'est pas créée
  automatiquement comme effet pending.
