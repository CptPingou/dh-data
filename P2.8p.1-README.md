# P2.8p.1 — Hunt Effect Lifecycle

Ajoute `pendingEffects` à l'état Engagement v2 et les opérations génériques
`queueEffect`, `pendingEffects` et `consumeEffects`.

- Feinte d'approche : l'effet de réaction est enregistré lorsqu'une réaction est déclenchée.
- Guidage du Finisher : l'effet devient pending après paiement du Support ; le Finisher suivant l'affiche puis le consomme.
- Frappe de rupture : l'effet Finisher est enregistré seulement sur une conversion réussie.
- Aucun modificateur ou état Daggerheart n'est appliqué automatiquement.
- Un nouvel Opener repart avec `pendingEffects: []`.

Test :
```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
api.engagementState.status();
api.engagementState.pendingEffects();
```
Après Guidage, attendre `finisher-attack-bonus` / `next-finisher-attack` / `pending`.
Après le Finisher, l'effet doit être `consumed`. Après un nouvel Opener, la liste repart vide.
