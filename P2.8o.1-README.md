# P2.8o.1 — Engagement State + budget d'Action MH

Patch-only depuis les fichiers courants fournis.

## Ajout
`engagement-state.mjs` crée un état World persistant :
- `open`
- `openerActorId`
- `designatedFinisherActorId`
- `participants`
- consommation d'une Action Monster Hunter par acteur et par Engagement.

## Cycle
- Opener : ouvre une nouvelle fenêtre d'Engagement, remet le budget des participants à zéro, puis consomme l'Action MH de l'Opener.
- Support : consomme l'Action MH du Support avant de payer son Espoir.
- Finisher : vérifie le Finisher désigné lorsqu'il existe, consomme son Action MH, résout la conversion puis ferme l'Engagement.
- si aucun Finisher n'est encore enregistré, le fonctionnement oral actuel reste autorisé (`verified:false`) pour ne pas bloquer la table avant l'UI de désignation.
- `engagement.reset()` remet Opportunity à 0 ET réinitialise l'état.

## Important
Cette étape refuse le **traitement Monster Hunter** d'une deuxième action (coût/OP/effet).
Elle n'annule pas rétroactivement un jet Foundryborne déjà lancé : le verrou pré-roll/UI viendra avec la couche d'orchestration suivante.

## Tests console
```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
api.engagementState.status();
api.engagement.snapshot();
```

Test manuel de désignation :
```js
await api.engagementState.reset();
await api.engagementState.open({ openerActor: game.actors.getName("TEST") });
api.engagementState.status();
```

Pour désigner un autre acteur :
```js
await api.engagementState.designateFinisher(game.actors.getName("NOM DU FINISHER"));
```
