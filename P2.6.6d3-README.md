# P2.6.6d3

Changed-files-only patch for DH Data.

1. Copy over repository root.
2. Run:
   `python .\tools\consolidate_character_options_fr.py`
3. Expected: `entries: 102`, `green: true`.
4. The generated `data/locales/fr/character-options.json` is canonical and should be committed.
5. `d2a.json`, `d2b.json`, `d2c.json` remain drafts and are ignored by the locale exporter. After validating `character-options.json`, delete/move them before commit.
6. Then run the normal locale export toward Toolkit.

Important: feature IDs are not in the SRD identity indexes, so this d3 exporter activates the 39 root ancestry/community IDs. Native feature overlays remain present in `character-options.json` for P2.6.6d4, where Toolkit native-document localization will consume them.
