# P2.10k.3 — Réparation adversaires Monster Hunter

## But

- restaurer l'affichage des composants du Tetsucabra dans `system.notes`;
- conserver les features embarquées ;
- supprimer les doublons `dh-adversaries` partageant le même `sourceId`;
- empêcher une course delete/create lorsque deux imports du même adversaire
  se déclenchent en même temps ;
- fournir un import dédié pour le lot Monster Hunter actuel.

## Sources

Le Tetsucabra porte actuellement deux entrées `hunting.loot` :

- Cuir
- Crocs

La Reine Vespoid et le Vespoid Minion ne portent pas encore de `hunting.loot`.
Aucun composant n'est inventé pour eux dans cette passe.

## Import de réparation

Après déploiement, depuis la console Foundry MJ :

```js
const mh = await import(
  "/modules/daggerheart-campaign-toolkit/scripts/pilot-import.mjs"
);

await mh.importMonsterHunterAdversaries();
```

Puis contrôler :

```js
const p = game.packs.get(
  "daggerheart-campaign-toolkit.dh-adversaries"
);
const docs = await p.getDocuments();

console.table(
  docs
    .filter(a => /tetsu|vespoid/i.test(a.name))
    .map(a => ({
      id: a.id,
      name: a.name,
      sourceId:
        a.flags?.["daggerheart-campaign-toolkit"]?.sourceId,
      items: a.items?.size ?? 0,
      notes: a.system?.notes
    }))
);
```

Attendu : un seul principal Tetsucabra, une seule Reine Vespoid, un seul
Vespoid Minion. Le Tetsucabra doit montrer `Composants / Récolte` avec Cuir et
Crocs dans Notes.
