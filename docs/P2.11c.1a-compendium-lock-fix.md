# P2.11c.1a — Fix verrouillage des compendiums

## Symptôme

Foundry v14 rejetait la première création de feature :

`You may not create documents in the locked compendium "daggerheart-campaign-toolkit.dh-features".`

## Cause

P2.11c.1 ouvrait et refermait les compendiums dans plusieurs helpers imbriqués.
L'import Artificier est une transaction multi-documents et multi-packs ; les
verrous locaux rendaient la séquence fragile.

## Correctif

`importArtificerArtillery()` ouvre désormais une seule transaction sur :

- `dh-features`
- `dh-domain-cards`
- `dh-classes`
- `dh-subclasses`

Les quatre packs restent déverrouillés pendant toute l'opération, puis sont
reverrouillés dans un `finally`, même si une erreur interrompt l'import.

Les helpers de création ne changent plus eux-mêmes l'état `locked`.

## Test

```powershell
cd C:\dev\dh-data

powershell -ExecutionPolicy Bypass `
  -File ".\tools\verify-p2.11c.1a.ps1"
```

Après GREEN : robocopy, F5, puis relancer simplement :

```js
const hb = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/pilot-import.mjs?v=${Date.now()}`
);

await hb.importArtificerArtillery();
```

L'import est basé sur `sourceId` et remplace les éventuels documents créés lors
d'une tentative précédente ; il peut donc être relancé sans nettoyage manuel.

Puis :

```js
await hb.artificerArtilleryStatus();
```
