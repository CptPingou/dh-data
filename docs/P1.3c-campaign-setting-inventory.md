# P1.3c — Campaign-setting source inventory

This phase inventories the PDFs currently available under `pdf/` before any
additional campaign-setting extraction.

It does **not** copy campaign prose. It records source metadata, file hashes,
basic PDF readability, known corpus identity, and whether an unknown PDF shows
signals such as `CAMPAIGN FRAME` or `CAMPAIGN MECHANICS`.

Known roles:

- SRD 2.0 → public baseline, already extracted.
- Hope & Fear → private delta, already extracted through P1.3b.
- Hope & Fear card PDF → reference asset.
- Homebrew Kit → design guidance for P1.4.
- Blood Hunter v1.5 → playtest corpus for P1.5 coverage.

Unknown PDFs with campaign-setting signals are registered as P1.3d candidates.

## Run

From `C:\dev\DH Data>`:

```bat
python tools\inventory_campaign_setting_sources.py "pdf"
```

### Interpretation

`validation: GREEN` with
`additional_campaign_setting_candidate_count: 0` is valid: it means there are
no additional campaign-setting PDFs in the current local corpus. In that case,
P1.3d is a no-op until new setting sources are added and the roadmap can move
to P1.4 Primitive Census.

If one or more candidates are found, P1.3d extracts them before P1.4.
