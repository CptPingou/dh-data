# P2.10h.2c — Patcher robuste du retour partiel

Le patch précédent recherchait un bloc texte complet de `unloadToActor()`.
Cette version ne dépend plus de la mise en forme exacte.

Elle repère seulement :

```js
const available = Math.max(1, Number(entry.quantity) || 1);
```

puis :

```js
const qty = quantity == null ? available : Math.max(1, Number(quantity) || 1);
```

et insère la sélection de quantité entre les deux.

Le reste de `unloadToActor()` est laissé intact.
