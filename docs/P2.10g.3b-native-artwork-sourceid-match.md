# P2.10g.3b — Matching artwork par sourceId canonique

Le premier dry-run ne retrouvait que 3/358 armes et 0 armor/consumables/loot.

Cause :
- les sources FR ont des noms traduits ;
- les packs natifs Foundryborne n'exposent pas de `sourceId` ;
- la plupart des équipements n'ont pas de `mechanicsReconstruction.nativeId`.

La donnée FR contient toutefois un identifiant canonique stable, par exemple :

- `srd-2.0.consumable.core-01-stride-potion`
- `srd-2.0.weapon.primary.2.improved-rope-dart`

Le script extrait le dernier segment et le compare au slug du nom natif :

- `core-01-stride-potion` -> `stride-potion`
- `Improved Rope Dart` -> `improved-rope-dart`

Ordre de matching :
1. nativeId existant
2. nativeName canonique
3. sourceId/canonicalSourceId -> slug natif
4. nom courant normalisé, en dernier recours

Aucune écriture ne doit être faite avant validation du nouveau `--dry-run`.
