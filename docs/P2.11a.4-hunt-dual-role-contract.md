# P2.11a.4 — Double axe des cartes Chasse

Ce jalon restaure explicitement le contrat de conception déjà utilisé par le
projet : une carte Chasse peut porter un rôle de combat, un rôle de chasse,
les deux, ou aucun sur un axe donné.

## Axe combat

Valeurs :
- `opener`
- `finisher`
- `support`
- `null`

Ces rôles décrivent uniquement l'Engagement Monster Hunter et son interaction
avec Opportunity.

## Axe chasse

Valeurs actuellement cristallisées :
- `preparation`
- `tracking`
- `knowledge`
- `extraction`
- `logistics`
- `null`

Ces rôles décrivent les fonctions hors Engagement : préparation, traque,
lecture du monstre/biome, dépeçage et logistique.
