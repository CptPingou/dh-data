# P2.11a.2b — Correctif migration runtime legacy

Le runtime a retourné `found: 0` parce que les anciennes cartes Monster Hunter
présentes dans `dh-domain-cards` ne portent pas nécessairement les flags
`sourcePath`/`sourceId` ajoutés par le rail plus récent.

Le filtre de P2.11a.2a était donc trop strict.

## Discriminateur runtime retenu

Une carte legacy Chasse est reconnue par :

1. son nom appartient à la liste des 17 cartes ;
2. son domaine runtime est `valor` (legacy) ou `hunt` (déjà migré).

Cela suffit pour distinguer `Tacticien` :
- `Tacticien` Monster Hunter : `valor` -> candidat ;
- `Tacticien` core : `bone` -> exclu.

Aucun contenu, action, effect, niveau, Recall Cost ou sourceId n'est modifié.
Seul `system.domain` passe de `valor` à `hunt` et l'ancienne icône Valor peut
être remplacée par l'icône Hunt temporaire.
