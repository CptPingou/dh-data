# P2.10j.3c — Déclenchement du menu sur pointerup

Correction de P2.10j.3b.

Cause visée :
`preventDefault()` sur `pointerdown` pouvait empêcher le `click`
suivant dans le contexte du renderer Foundry.

Changements :
- le trigger `⋮` devient un `div role="button"`;
- ouverture sur `pointerup`;
- `pointerdown` bloque seulement la propagation;
- fallback clavier Enter/Espace;
- menu portal j.3b conservé.

Aucune modification des actions métier.
