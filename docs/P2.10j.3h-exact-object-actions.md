# P2.10j.3h — Ciblage DOM exact de la colonne Objet

Basé sur le DOM réel fourni :

```html
<aside class="dct-expedition-item-panel">
  <section class="dct-expedition-item-detail" data-selected-entry-id="...">
    ...
    <div class="dct-expedition-item-actions">
      <button
        data-expedition-action="return-to-actor"
        data-container-id="..."
        data-entry-id="..."
      >
        Rendre au personnage
      </button>
    </div>
  </section>
</aside>
```

Les boutons toolkit sont ajoutés directement dans
`.dct-expedition-item-actions`.

Ordre :
- Rendre au personnage
- Consommer
- Modifier
- Supprimer

Ils utilisent le même contexte CSS natif que le bouton existant.

Chaque clic lit l'entrée sélectionnée depuis les attributs du bouton natif,
recharge le manifest frais, retrouve l'entrée, puis appelle l'API lifecycle.
