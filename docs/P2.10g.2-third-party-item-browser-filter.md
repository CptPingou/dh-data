# P2.10g.2 — Filtrage des sources tierces redondantes

Après P2.10g.1, cinq consommables anglais restaient visibles :

- Unique Food
- Luck Charm
- Healing Vial
- Beautiful Relic
- Arcane Rune

Le diagnostic runtime a montré qu'ils viennent de :

`daggerheart-quickactions.items`

Ils ne viennent ni de Foundryborne natif ni du toolkit.

P2.10g.2 ajoute une liste explicite de packs Item tiers redondants à exclure
du navigateur Daggerheart, sans désactiver leurs modules.

Liste actuelle :

- `daggerheart-quickactions.items`

Le module Quick Actions reste actif ; seul son pack Item est ignoré par
l'ItemBrowser.

Diagnostic :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
api.itemBrowserSources.status();
```

Le résultat expose maintenant `ownedRows` et `thirdPartyRows`.
