# P2.11d.2b — ItemLink runtime Foundryborne

Le dump runtime confirme que l'ItemLink Foundryborne 2.10.5 n'est pas un
DataModel sérialisable :

```text
ownKeys: ["type", "item", "uuid"]
_source: null
toObject: null
toJSON: null
```

`item` contient directement le `DhItem` résolu.

## Cause du bug

- avant 2a : `item` restait celui du specimen Blood Hunter ;
- en 2a : suppression de `item` => `uuid: null`, `item: undefined`.

## Correctif 2b

Le remapping conserve la forme runtime et remplace ensemble :

```js
link.type = wantedType;
link.item = doc;
link.uuid = doc.uuid;
```

Ainsi le lien possède immédiatement le vrai `DhItem` cible et son UUID.
