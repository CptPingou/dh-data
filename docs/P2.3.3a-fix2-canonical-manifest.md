# P2.3.3a fix2 — canonical import manifest

The full Foundry export no longer discovers entities by recursively scanning `data/`.
It reads only files declared in `config/foundry-import-manifest.json`.

Important consequences:
- `adversaries-candidate.json` is excluded; only `adversaries/adversaries.json` is authoritative.
- `indexes/domain-cards-dread.json` is excluded; the ten domain files are authoritative.
- the manifest, not incidental `kind` metadata, determines the entity family.
- the 1012-count safety gate remains mandatory before `full-import.json` is replaced.
