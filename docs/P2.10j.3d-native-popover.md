# P2.10j.3d — Menu via Popover API native

Remplace entièrement l'ouverture JS du menu `⋮`.

Le bouton utilise désormais :

- `popovertarget`
- `popovertargetaction="toggle"`

Le menu utilise :

- `popover="auto"`
- `:popover-open`

Le navigateur gère donc nativement l'ouverture, la fermeture et le top layer.

Les actions métier restent inchangées :
- Consommer
- Marquer modifié
- Supprimer

Le popover est ajouté à `document.body` et positionné près du trigger à
l'ouverture.
