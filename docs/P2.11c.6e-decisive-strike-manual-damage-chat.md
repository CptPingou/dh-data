# P2.11c.6e — Frappe décisive : dégâts manuels via chat

Décision : abandon de l'automatisation du bonus de dégâts.

Conservé :
- dépense automatique des Cob Rounds ;
- +1 au jet d'attaque par Cob Round ;
- consommation de Frappe décisive sur la prochaine attaque.

Remplacé :
- aucun bonus de dégâts n'est injecté dans Foundryborne ;
- le chat affiche au moment de la consommation :
  **Ajoutez manuellement +Xd6 dégâts**, avec X = 2 × Cob dépensés.

Exemple : 2 Cob → +4d6 dégâts.
