# P2.11c.6a — Frappe décisive

Source canonique du corpus Artillery :

- une fois par repos long ;
- avant un jet d'attaque ;
- dépense toutes les ressources d'action actuelles (Cob Rounds / équivalent) ;
- +1 au jet d'attaque par ressource dépensée ;
- +2d6 dégâts par ressource dépensée ;
- en cas de réussite, la cible ne peut pas effectuer de Réactions jusqu'au
  début de la prochaine action du personnage.

## Implémenté

`Armer Frappe décisive` apparaît comme Action sur la carte.

À l'utilisation :

1. le runtime lit le nombre de Cob Rounds ;
2. les dépense tous ;
3. crée un effet Actor temporaire :
   - `+N` aux jets d'attaque ;
   - `+2N d6` aux dégâts physiques et magiques ;
4. la prochaine attaque profite de l'effet ;
5. dès que son ChatMessage est créé, le runtime supprime l'effet et l'état
   armé afin qu'il ne fuit pas vers une attaque ultérieure.

La limite 1/repos long reste gérée par l'Action native.

## Resté manuel en 6a

L'interdiction de Réactions sur la cible après une attaque réussie reste
volontairement manuelle : on n'a pas encore validé dans le runtime actuel
le champ de succès non critique ni un specimen de durée « jusqu'au début de
votre prochaine action ». Aucun schéma n'est inventé.
