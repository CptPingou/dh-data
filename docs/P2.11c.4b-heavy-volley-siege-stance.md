# P2.11c.4b — Volée lourde + Posture de siège

## Volée lourde

Automatisé :
- effet natif transférable ;
- +1d6 aux dégâts physiques ;
- +1d6 aux dégâts magiques.

Limite volontaire :
- la source indique un scaling d6/d8/d10/d12 selon le Tier ;
- aucun specimen natif du corpus ne montre une expression Tier sûre pour une
  taille de dé dynamique ;
- P2.11c.4b automatise donc le Tier 1 et conserve la table de scaling dans le
  flag Toolkit.

On n'invente pas de syntaxe `@tier`.

## Posture de siège

Automatisé :
- Action native ;
- 1 utilisation par repos ;
- applique un effet Posture de siège ;
- +2 aux jets d'attaque ;
- +1d8 aux dégâts physiques et magiques.

Manuel pour l'instant :
- immunité au déplacement forcé ;
- retirer la posture dès que le personnage se déplace.
