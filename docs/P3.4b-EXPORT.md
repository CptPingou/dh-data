# P3.4b — Règles de projection

| Source Foundry | Destination JSON | Règle |
|---|---|---|
| `expeditionManifests[expeditionId]` | `expeditionId`, `revision`, `phase`, `authority` | Reprise directe, lecture seule |
| `manifest.characters` | `characters[]` | `characterId` + Actor UUID, acteur résolu |
| `containers` sac à dos | `characters[].backpack` | Association via `holderRef.id === characterId`, exactement un sac par PJ |
| `entry.itemRef.sourceId` | `contents[].sourceId` | Obligatoire |
| `entry.quantity` | `contents[].quantity` | Entier positif, ne jamais lire `snapshot.system.quantity` |
| `entry.itemRef.uuid` | `contents[].foundryItemUuid` | Référence secondaire |
| `manifest.caravan` | `caravan.structure` | Copie complète (roues, PV, layout, cargoSlots) |
| `caravan.components[].containerId` | `caravan.containers[]` | Sélection des seuls conteneurs cargo associés |
| `materialKnowledge.actorKnowledge[Actor UUID]` | `characters[].materialKnowledge` | Connaissances individuelles, couverture `captured` même si vide |
| `materialKnowledge.partyKnowledge` | `research.partyMaterialKnowledge` | Si propriété documentée globale : BLOQUER ; sinon objet vide |
| `researchKnowledge.revelations[]` | `research.revelations[]` | Filtrer par destinataires de l'expédition, convertir Actor UUID en characterId |
| `sharedWith:['party']` | — | BLOQUER : portée mondiale ambiguë |
| `ground`, `fob`, `ledger`, `fob` constructions | — | Exclusion |

## Sécurité et intégrité

- Échec fermé sur acteurs non résolus, sac absent/ambigu, identifiants d'objets absents, quantités invalides, liens cargo manquants, destinataires externes et partage global non isolé.
- Le fichier contient potentiellement des révélations privées : stockage privé et filtrage serveur obligatoire côté web.
- `metadata.exampleOnly` est absent : contrairement à l'exemple P3.4a.1, c'est une extraction réelle. Il faut néanmoins valider le fichier avant de l'utiliser.
- Une connaissance non présente est invisible par défaut ; l'exporteur n'invente aucun état `hidden`.
- Le transfert d'autorité web ↔ Foundry et la remise à zéro du stock FOB restent réservés à P3.4c/P3.4d.
