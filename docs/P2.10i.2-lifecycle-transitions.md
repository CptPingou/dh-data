# P2.10i.2 — Transitions lifecycle

API ajoutée :

- `consume(manifest, { containerId, entryId, quantity, note })`
- `modify(manifest, { containerId, entryId, item, snapshot, itemRefPatch, note })`
- `delete(manifest, { containerId, entryId, note })`

`consume` décrémente réellement `entry.quantity`. À zéro :
- state = `consumed`
- quantity = 0
- slotId = null

`delete` conserve l'entrée pour l'historique mais passe :
- state = `deleted`
- quantity = 0
- slotId = null

`modify` remplace le snapshot et/ou les champs de référence fournis et passe
l'entrée à `modified`.

Chaque transition ajoute une entrée à `itemRef.lifecycle.history`.

Le patcher `apply_p2_10i_2_manifest.py` localise le moteur manifest par son
validateur et adapte la validation/capacité pour les états terminaux.
