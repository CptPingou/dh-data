# P2.10h.5d — Rollback transactionnel ciblé

Construit directement à partir des fichiers source réels.

## Actor → Backpack

Avant mutation :
- snapshot du manifest ;
- snapshot de l'Item Actor concerné.

Après confirmation de `loadFromActor()`, toute exception déclenche :
- restauration du manifest persistant ;
- restauration de la quantité de l'Item Actor ;
- recréation de cet Item avec son ID s'il avait été supprimé.

## Backpack → Actor

Avant mutation Actor :
- snapshot du manifest.

En cas d'exception après mutation :
- restauration du manifest en mémoire ;
- suppression de l'Item créé, ou
- restauration de la quantité du stack fusionné.

Aucun autre Item de l'Actor n'est supprimé ou recréé.
