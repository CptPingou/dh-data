# P2.11a.1 — Domaine Chasse : vertical slice

Objectif : valider le rail complet d'un domaine homebrew Monster Hunter avant
d'écrire les 21 cartes.

## Domaine

Identifiant Foundryborne : `hunt`
Nom affiché : `Chasse`

Le Toolkit ajoute le domaine dans le réglage Homebrew de Foundryborne, au lieu
de modifier le système Daggerheart.

L'icône utilisée ici est volontairement temporaire. Le jalon suivant pourra
remplacer `src` par l'icône custom Chasse sans modifier les sourceIds.

## Carte pilote

- Lecture de la proie
- Niveau 1
- Ability
- Recall Cost 0
- automatisation : aucune, texte uniquement

Cette carte sert d'abord à valider :
source JSON -> domaine Foundryborne -> import Toolkit -> dh-domain-cards ->
fiche/affichage.

## Import runtime

Console MJ :

```js
const mh = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/pilot-import.mjs?v=${Date.now()}`
);
await mh.importHuntPilot();
```

Attendu :
- `green: true`
- domaine `hunt`
- carte `Lecture de la proie`
- `domain: "hunt"`
- `level: 1`
- `recallCost: 0`
- `cardType: "ability"`

Ensuite ouvrir `dh-domain-cards` et la carte.

Si Foundryborne ne rafraîchit pas immédiatement ses choix de domaines après
l'écriture du setting Homebrew, faire un F5 puis relancer exactement la même
commande. L'import est idempotent pour ce sourceId : l'ancienne copie pilote est
supprimée avant recréation.
