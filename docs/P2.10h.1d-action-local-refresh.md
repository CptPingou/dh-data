# P2.10h.1d — Refresh local à l'action Actor -> Backpack

Le refresh n'est plus traité comme une recherche générique de fenêtres.

Après un transfert réussi :
1. le manifest est sauvegardé ;
2. le débit Actor est appliqué ;
3. le manifest est relu depuis `expeditionManifest.load(expeditionId)` ;
4. `expeditionManifest.open(expeditionId)` fournit l'instance de fenêtre ;
5. si l'instance expose déjà une propriété `manifest`, `expeditionManifest`,
   `expedition` ou leur équivalent dans `data`, elle est remplacée par le
   manifest fraîchement relu ;
6. la fenêtre est rerendue avec `force:true`.

Le refresh appartient donc désormais directement à l'action
"Mettre dans le sac à dos".

La correction quantité 0 reste inchangée.
Le stack des entrées identiques reste hors scope jusqu'à P2.10h.3.
