# P2.10j.4a — Séparation UI Joueur / MJ

## MJ

La fenêtre conserve deux onglets :

- `Inventaire`
- `MJ`

`Inventaire` contient le renderer existant :

- Conteneurs
- Contenu
- Objet

`MJ` contient :

- résumé Lifecycle
- blocs WEB / FOUNDRY
- Journal des événements

Le bouton `Fermer` reste en dehors des onglets.

## Joueur

Aucun onglet `MJ` n'est construit.

Les éléments suivants sont retirés de la fenêtre :

- Lifecycle
- WEB / FOUNDRY
- Journal des événements
- badges lifecycle sur les objets

Le browser d'inventaire existant reste inchangé.

## Technique

Les nœuds natifs sont déplacés, et non clonés, afin de préserver leurs
listeners existants.

Ce patch ne modifie pas encore les permissions métier des actions Objet.
La couche d'autorité/permissions reste prévue en P2.10k.
