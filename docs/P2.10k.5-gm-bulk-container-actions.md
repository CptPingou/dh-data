# P2.10k.5 — Actions MJ en masse sur les conteneurs

## 1. Vider le Sol

Dans le panneau MJ des conteneurs partagés, la carte `Sol` reçoit un bouton :

`Vider le Sol`

- MJ uniquement.
- Demande de confirmation.
- Supprime toutes les entrées présentes au Sol.
- Utilise `expeditionManifest.lose()` entrée par entrée afin de conserver le ledger.
- Sauvegarde le manifest une seule fois à la fin.
- Broadcast et refresh des clients.

## 2. Tout transférer un sac à dos vers le Sol

Chaque carte de sac à dos dans le panneau MJ reçoit :

`Tout transférer au Sol`

- MJ uniquement.
- Demande de confirmation.
- Utilise `expeditionManifest.transfer()` pour chaque entrée.
- Respecte capacité, slots et règles du Sol.
- S'arrête au premier transfert refusé (par exemple Sol plein).
- Les transferts déjà réussis sont conservés et sauvegardés.
- Affiche le nombre transféré et le nombre restant.
- Broadcast et refresh des clients.

## Test

1. Ajouter plusieurs objets au Sol.
2. Onglet MJ -> Sol -> `Vider le Sol`.
3. Annuler : rien ne doit changer.
4. Recommencer et confirmer : Sol vide sur MJ + joueur.
5. Remplir un sac avec plusieurs objets.
6. Onglet MJ -> sac -> `Tout transférer au Sol`.
7. Confirmer : tout le contenu compatible doit aller au Sol.
8. Tester avec un Sol presque plein :
   - les transferts possibles passent ;
   - le reste demeure dans le sac ;
   - notification explicite.
9. Vérifier que l'onglet MJ reste sélectionné après refresh.
