# P2.10j.3i — Carte Daggerheart native lors de Consommer

Le menu natif Foundryborne a confirmé que `Send to Chat` appelle :

```js
(await getDocFromElement(target)).toChat(this.document.uuid)
```

Le bouton `Consommer` du paquetage reproduit désormais cet appel avant la
transition lifecycle.

Résolution de l'Item :
1. `itemRef.uuid`
2. `itemRef.sourceId`
3. Item temporaire construit depuis `itemRef.snapshot`

L'Item temporaire n'est pas ajouté à l'inventaire du personnage.

Flux :
1. recharger le manifest frais ;
2. résoudre Actor + Item ;
3. `item.toChat(actor.uuid)` ;
4. exécuter la consommation existante ;
5. conserver archivage/refresh existants.
