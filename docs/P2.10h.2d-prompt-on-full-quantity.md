# P2.10h.2d — Prompt même si le bouton passe la quantité totale

Diagnostic :
le bouton "Retour au personnage" passe vraisemblablement la quantité
totale de l'entrée à `unloadToActor()`.

Le patch h.2c ne demandait une quantité que lorsque `quantity == null`,
donc le bouton déclenchait toujours un retour complet.

Nouvelle règle :

```js
if (
  available > 1 &&
  (
    requestedQuantity == null ||
    Number(requestedQuantity) >= available
  )
) {
  // demander la quantité
}
```

Ainsi :

- UI bouton : quantité totale reçue -> prompt ;
- appel API sans quantité -> prompt ;
- appel API explicitement partiel (`2` sur `5`) -> pas de prompt ;
- entrée `×1` -> retour direct.
