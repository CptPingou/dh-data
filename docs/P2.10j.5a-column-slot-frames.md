# P2.10j.5a — Cadres et fonds simples

Habillage CSS uniquement.

## Colonnes

Les trois enfants directs de `.dct-expedition-browser` reçoivent :

- bordure discrète ;
- coins arrondis ;
- fond sombre légèrement différent par colonne ;
- padding interne.

## Slots

- slot vide : fond gris sombre ;
- slot occupé : fond brun chaud discret ;
- bordure plus lisible ;
- hover légèrement renforcé.

Aucun asset graphique n'est utilisé.
Aucune logique de drag/drop, sélection, lifecycle ou transfert n'est modifiée.
