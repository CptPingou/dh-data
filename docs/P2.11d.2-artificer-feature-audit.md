# P2.11d.2 — Audit des features de classe Artificier

## Décision

Cette étape ne crée volontairement aucune nouvelle automation.

### Deus Ex Machina — texte only

La source donne un coût de 3 Espoir et décrit deux usages, mais elle ne précise
pas à quel jet ou quelle valeur le ou les d12 sont ajoutés. Ne pas extrapoler.

### Bricolage magique — texte only

La feature est complète mais essentiellement narrative. Son plafond est égal au
modificateur de Connaissance. Aucun runtime supplémentaire n'est nécessaire à ce
stade.

### Infusions d'Artificier — P2.11d.3

Contrat exploitable :

- création pendant un repos court ou long ;
- durée jusqu'au prochain repos long ;
- capacité : niveaux 1/3/5/7/9 -> 2/4/6/8/10 infusions ;
- sur dégâts issus d'une réussite critique : d6 ;
  - 1 : perte de l'infusion ;
  - 2 : perte de 1 PV ;
  - 3 : +1 Stress ;
  - 4–6 : rien ;
- si plusieurs infusions existent, la plus récente est affectée en premier ;
- 1 Espoir, une fois par session, peut empêcher cette conséquence.

Lacune bloquante : la source annonce des bonus d'infusion mais ne fournit pas
leur liste ni leurs valeurs. P2.11d.3 doit donc construire le cadre
d'infusion, pas inventer les bonus.

### Arcane Jolt — hors périmètre

Cette feature n'apparaît pas dans la source Artificier canonique actuellement
importée. Elle est retirée de la roadmap tant qu'une source explicite n'est pas
fournie.

## Prochaine étape

P2.11d.3 : représentation native des Infusions et gestion de leur capacité /
cycle de vie, sans bonus mécaniques inventés.
