# P2.11c.6c — Frappe décisive : composition des dégâts

Le dump runtime 2.10.5 montre :

- l'Action de la Baguette conserve son dégât principal `@profd6+1` ;
- l'effet Frappe décisive ajoute correctement `+2` au jet d'attaque ;
- le hook `daggerheart.preDamageAction` reçoit encore l'Action native complète ;
- `config.extraFormula` est vide et disponible ;
- l'ancien bonus Actor `damage.dice = ["4d6"]` remplaçait le dégât principal
  au moment de la construction du DamageRoll.

P2.11c.6c change uniquement la couche dégâts :

- l'ActiveEffect ne porte plus que le bonus d'attaque `+N` ;
- au hook `daggerheart.preDamageAction`, tant que Frappe décisive est armée,
  le runtime ajoute `2N d6` à `config.extraFormula` ;
- le dégât de base de l'arme reste intact ;
- la suppression de l'effet après l'attaque reste inchangée.
