# P2.11d.3f.0 – Diagnostic du repos long natif

La sonde est non destructive. Elle enregistre les changements Actor, ActiveEffect et ChatMessage émis par Foundryborne 2.10.6 pour identifier un signal de fin de repos **après confirmation**. Elle ne déduit jamais la validation d'une variation de PV ou Stress.

## Procédure console (MJ)

```js
const { artificerRestDiagnostic: restProbe } = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/artificer-rest-diagnostic.mjs?v=${Date.now()}`
);
restProbe.start();
restProbe.mark('before-cancel');
```

Ouvrir un repos long natif, puis **annuler**, et saisir :

```js
restProbe.mark('after-cancel-before-confirm');
```

Ouvrir un nouveau repos long natif, le **valider réellement**, puis :

```js
restProbe.mark('after-confirm');
restProbe.summary();
copy(JSON.stringify(restProbe.stop(), null, 2));
```

Coller ensuite ce JSON dans la conversation. Si besoin, arrêter à tout moment : `restProbe.stop()`.

Ne **pas** supprimer les infusions pendant le diagnostic. Ne pas inventer un hook de repos : une fois le signal réel identifié, le bridge P2.11d.3f utilisera le même signal de fin et ajoutera une protection anti-double-expiration côté registre mondial.
