# P2.10h.1e — Refresh du dialog d'expédition

Diagnostic :
la fenêtre d'expédition n'est pas une Application Foundry enregistrée.
Elle est rendue comme :

- tag : `DIALOG`
- class : `application dialog`
- titre/contenu : `Préparer l’expédition — ...`

Correction :
après un transfert Actor -> Backpack réussi :

1. recharger le manifest depuis le storage ;
2. trouver le `dialog.application.dialog` contenant `Préparer l’expédition` ;
3. fermer ce dialog ;
4. appeler `api.expeditionManifest.open(freshManifest)` avec le manifest complet.

Ce chemin reproduit automatiquement le comportement manuel déjà validé :
fermer puis rouvrir la fenêtre.

Important :
`expeditionManifest.open()` ne doit jamais recevoir l'expeditionId brut.
