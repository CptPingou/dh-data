# P2.10j.5b — Nettoyage de la vue joueur

## Joueur

Dans la colonne `Objet` :

- `Modifier` n'est plus proposé ;
- les références techniques de type `Actor.*`, `Item.*` ou `Compendium.*`
  ne sont plus affichées.

Les actions conservées sont :

- Rendre au personnage
- Consommer
- Supprimer

## MJ

- `Modifier` reste disponible ;
- les références techniques restent visibles.

Aucune logique lifecycle n'est supprimée.
