# P1.1b — Extracteur SRD 2.0

Cette passe enlève le dernier blocage de l'extraction industrielle.

Le PDF officiel SRD 2.0 est bien accessible publiquement et son appendice
`Domain Card Reference` couvre les pages imprimées 206–224. L'environnement
ChatGPT peut lire et citer le PDF, mais ne me fournit pas directement ses octets
au runtime Python. Le parseur est donc livré dans la base neutre.

## Exécution

Depuis la racine `daggerheart-data` :

```bash
pip install pypdf
python tools/extract_srd2_domain_cards.py X:\chemin\DH_SRD_2_2026_08_25.pdf
```

Sortie attendue :

```text
data/srd-2.0/domain-cards/
├── arcana.json
├── blade.json
├── bone.json
├── codex.json
├── dread.json
├── grace.json
├── midnight.json
├── sage.json
├── splendor.json
├── valor.json
└── manifest.json
```

Le script refuse de passer GREEN si :
- le total n'est pas exactement 210 ;
- un domaine n'a pas exactement 21 cartes ;
- des IDs sont dupliqués ;
- niveau/type/Recall Cost sont invalides.

Le texte SRD est conservé dans `content.rules_text`, mais les identités et
métadonnées mécaniques sont séparées dans `rules`.

## Important

Cette archive peut être fusionnée maintenant dans le dossier NAS :
elle ajoute uniquement du tooling et n'écrase pas les données déjà validées.
