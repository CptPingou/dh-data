# P2.3.3j — Normalisation des features adversaires / environnements

## Objectif

Préparer une représentation neutre et structurée des features SRD avant toute création d'Items embarqués Foundryborne.

Cette étape **n'automatise aucune feature** et **ne crée aucun Item Foundry**. Elle reste dans DH-DATA.

## Traitement

Le script `tools/normalize_srd2_adversary_environment_features.py` :

- conserve `features_text` intact comme provenance brute ;
- ajoute un tableau neutre `features[]` avec `name`, `type` (`Passive`, `Action`, `Reaction`) et `text` ;
- corrige uniquement une liste explicite d'artefacts d'extraction PDF (`/comma.tab`, `/period.tab`, `/hyphen.tab`, chiffres `.tnum`, ligatures connues) ;
- coupe un bloc uniquement lorsqu'il contient le début non ambigu du stat block d'un **autre adversaire canonique** (`<Nom> Tier <rôle>`) ;
- ajoute `features_normalization` par document pour tracer le statut et une éventuelle contamination retirée ;
- écrit l'audit `docs/audits/P2.3.3j-feature-normalization.json`.

## Résultat du corpus courant

- Adversaires : **264 documents / 899 features structurées**
- Environnements : **47 documents / 189 features structurées**
- Total : **311 documents / 1088 features structurées**
- Blocs non séparables : **0**
- Contaminations inter-stat-block supprimées : **2**
  - `Acid Burrower` contenait le début du stat block `Bear`
  - `Siren` contenait le début du stat block `Sprite`
- Contaminations résiduelles détectées : **0**
- Statut : **GREEN**

## Commande de validation

Depuis la racine `DH Data` :

```bat
python tools\normalize_srd2_adversary_environment_features.py
```

Sortie attendue :

```text
P2.3.3j feature normalization
  adversaries: 264 docs / 899 features
  environments: 47 docs / 189 features
  unsplit blocks: 0
  cross-stat contamination removed: 2
  residual contamination: 0
  GREEN: True
```

## Stop criterion

P2.3.3j est fermé lorsque le script est GREEN sur le dépôt utilisateur. La conversion de `features[]` en embedded Items Foundryborne appartient à l'étape suivante.
