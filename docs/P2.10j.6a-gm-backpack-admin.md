# P2.10j.6a — Administration MJ des sacs à dos

Ajoute dans l'onglet MJ un panneau **Gestion des sacs à dos**.

Pour chaque backpack, le MJ peut :

- modifier le nom ;
- modifier le nombre de slots ;
- déposer le sac dans un lieu d'attente ;
- saisir ce lieu ;
- récupérer le même sac ultérieurement.

Le dépôt ne change ni `containerId`, ni `holderRef`, ni le contenu.
L'état est stocké dans `container.presentation.accessState` et le lieu dans
`container.presentation.storedAt`.

## Capacité

Une réduction sous le nombre d'objets présents est refusée. Lors d'un changement
de capacité, les entrées sont compactées sur des `slot-1..N` valides, sans
suppression d'objet.

## Joueur

Un backpack `stored` :

- est retiré de la vue inventaire joueur ;
- n'est plus sélectionné par l'action de fiche `Mettre dans le sac à dos`.

Le MJ conserve l'accès d'administration.

Cette étape reste une restriction fonctionnelle côté UI/runtime local. La
couche d'autorité multi-client complète reste prévue pour P2.10k.
