# P2.1.2 — Audit ciblé des modules installés

## Conclusion

L'audit est volontairement limité à la roadmap réelle. Nous n'allons pas chercher un module pour chacune des primitives P1.4.

La capture de l'environnement installé montre déjà suffisamment de briques pour éviter plusieurs développements inutiles.

## Décisions

| Module | Décision | Impact |
|---|---|---|
| Daggerheart - Homebrew | **fusionner** | absorber son contenu dans le nouveau module unique |
| Blood Hunter v1.5 | **fusionner** | absorber les compendiums/adapters déjà validés |
| Daggerheart: Colossus | **réutiliser** | boss multipart |
| Compact Sheets | **rester compatible** | conserver les Actors natifs Foundryborne |
| Containers | **UI seulement** | ne pas en faire le moteur de logistique |
| Custom Stat Tracker | **référence / usage ponctuel** | ne pas bâtir l'architecture dessus |
| Resource Macros | **réutiliser** | hooks de changements de ressources |
| Monk's Active Tile Triggers | **réutiliser si besoin** | triggers spatiaux et automatisation de scènes |
| Sequencer | **réutiliser** | animations / sons / séquences |
| Baileywiki Mass Edit | **outil d'authoring** | aucune dépendance métier |
| Hotbar Card View | **rester compatible** | argument supplémentaire pour garder de vraies Domain Cards |
| Distances | **rester compatible** | aucune duplication |
| Dice / FX / audio / Moulinette | **hors moteur** | compatibilité seulement |

## Vérifications web utiles

**Monk's Active Tile Triggers** est bien disponible et vérifié pour Foundry v14, avec déclencheurs d'entrée/sortie, macros, RollTables, effets, mouvements et autres actions de scène.

**Daggerheart: Compact Sheets** est actuellement vérifié pour Foundry v14 et remplace les sheets des `adversary` et `environment` tout en conservant les partials/actions du système. C'est une raison supplémentaire de produire des Actors Foundryborne natifs plutôt que des documents parallèles.

**Daggerheart: Custom Stat Tracker** est également v14 et fournit jusqu'à deux trackers personnalisés. C'est utile ponctuellement mais trop limité pour devenir notre modèle général de progression ou de craft.

L'écosystème Foundry v14 est désormais suffisamment mature pour que nous ne cherchions pas d'alternative externe sans besoin précis.

## Impact sur la roadmap

### P2.2 — module unique

Le module doit absorber :

```text
Daggerheart - Homebrew
Blood Hunter v1.5
```

mais **ne doit pas** embarquer Colossus, Sequencer, MATT ou Resource Macros.

Ces modules restent indépendants et pourront être utilisés lorsqu'une automatisation concrète en aura besoin.

### P2.5 — armes évolutives

Aucun module installé visible ne résout le besoin précis :

```text
Weapon native
+ catalogue d'Augments
+ déblocage narratif MJ
+ points attribués par MJ
+ choix PJ
+ état persistant sur l'arme
```

C'est donc toujours notre première extension maison probable.

### P2.6 — Domain Cards Chasse

On conserve absolument les vraies `domainCard` Foundryborne. Cela maintient la compatibilité avec les outils de cartes/hotbar déjà installés.

### P2.7 — Harvest / Craft / logistique

On ne choisit rien maintenant.

`Containers` peut aider à l'affichage mais ne suffit pas pour la logique de capacités/transferts. On décidera seulement lorsque la boucle `combat → harvest → craft → upgrade` sera testée.

### P2.8 — extensions à la demande

Nous avons déjà des candidats installés :

```text
boss multipart   → Colossus
triggers scène   → Monk's Active Tile Triggers
ressources       → Resource Macros
FX / sons        → Sequencer
```

## Décision P2.1.2

**GREEN.**

Aucun nouveau module n'est requis avant le travail sur les armes évolutives.

La suite est donc **P2.2 — squelette du module unique**.
