# P2.11c.5 — Runtime de ressource Artificier

## But

Créer un compteur `Cob Rounds` propre à l'Artificier, visible sur sa fiche et
pilotable par le Toolkit.

La donnée autoritaire vit sur l'Actor :

```text
flags.daggerheart-campaign-toolkit.artificer.resources.cobRounds
```

La feature embarquée affiche la valeur dans son nom :

```text
Cob Rounds [0]
Cob Rounds [1]
Cob Rounds [2]
...
```

Cela évite de dépendre d'un champ `system.resource` dont le schéma exact varie
selon les Items Foundryborne.

## API

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api.artificerResource;

await api.ensure(actor);
api.get(actor);

await api.set(actor, 2);
await api.gain(actor, 1);
await api.spend(actor, 1);
await api.spendAll(actor);

await api.status(actor);
```

## Incrémentation automatique

Un hook `createChatMessage` examine les jets.

Le compteur gagne `+1` uniquement si :
- l'Actor est un Artificier Toolkit ;
- il possède `Rythme de bataille` ;
- le message est identifié comme une attaque ;
- le jet est identifié comme critique.

La détection de critique utilise d'abord les flags Daggerheart explicites, puis
un fallback sur les deux d12 de Dualité.

Le message est mémorisé localement pour éviter un double incrément sur le même
ChatMessage.

## Test runtime

Après robocopy + F5, sur un Actor Artificier :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api.artificerResource;
const actor = game.actors.getName("NOM DU PJ");

await api.ensure(actor);
await api.set(actor, 0);
await api.gain(actor, 1);
await api.status(actor);
```

La feature doit devenir `Cob Rounds [1]`.

Puis remettre à zéro et faire un vrai critique d'attaque avec `Rythme de
bataille` présent sur le personnage. La feature doit passer automatiquement de
`[0]` à `[1]`.

Si l'auto-détection ne part pas sur le message réel de Foundryborne, lancer sur
le message concerné :

```js
api.inspectCriticalMessage(game.messages.contents.at(-1));
```

Le résultat indique séparément `attack`, `explicitCritical`,
`fallbackCritical`, `artificer` et `battleRhythm`, ce qui permettra d'ajuster le
seul adaptateur de lecture du ChatMessage sans toucher au compteur.
