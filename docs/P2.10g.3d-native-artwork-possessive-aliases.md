# P2.10g.3d — Native artwork possessive aliases

3c fixed long source IDs and `-s-` possessives but regressed historical matches
where Foundry names normalize by simply removing the apostrophe.

3d indexes both deterministic forms:

- `Adder's Fang`
  - `adders-fang`
  - `adder-s-fang`

- `Alistair's Torch`
  - `alistairs-torch`
  - `alistair-s-torch`

This restores matches such as:
- Adder's Fang
- Soldier's Pike
- Monett's Cloak
- Enchanter's Robes
- Cupbearer's Bezoar

while retaining:
- source-text suffix matching for consumables
- `Alistair-s` / `Paragon-s` loot matching
- rejection of ambiguous duplicate names unless all duplicates have the same artwork.

No fuzzy matching.
