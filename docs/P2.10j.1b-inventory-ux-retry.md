# P2.10j.1b — Injection UX robuste

Correction du déclenchement de P2.10j.1.

Le dialogue Foundry peut être inséré avant que son titre et son contenu
soient entièrement rendus. La détection précédente pouvait donc rater
`Préparer l’expédition`.

j.1b ajoute :

- plusieurs tentatives courtes après apparition du dialogue ;
- surveillance des mutations à l'intérieur d'un dialog Foundry ;
- hook `renderApplicationV2` comme second déclencheur ;
- maintien du hook toolkit `expeditionChanged`.

Aucun changement du renderer ni des données.
