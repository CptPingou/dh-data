# P2.3.3a fix3 — canonical manifest + DH-DATA shapes

The fix2 RED exposed three independent assumptions in the exporter:

1. SRD classes/subclasses currently live in canonical `indexes/classes.json` and `indexes/subclasses.json`, not dedicated folders.
2. Domain-card and Blood Hunter files must be recognized by stable `kind + id`; requiring `name/title` incorrectly rejected valid DH-DATA records.
3. The 12 combat-wheelchair weapon variants were absent from the weapon manifest. The manifest now includes the canonical equipment `*wheel*.json` file without reintroducing recursive corpus discovery.

The exporter remains fail-closed: it writes `full-import.json` only if all canonical patterns exist and the audited total is exactly 1012.
