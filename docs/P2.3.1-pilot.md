# P2.3.1 — Petit corpus pilote

Ce patch valide la chaîne réelle :

```text
daggerheart-data
→ export minimal
→ data/pilot.json dans le module
→ adapter JS
→ compendiums Foundry
→ documents natifs Foundryborne
```

Le pilote utilise exactement sept familles :

- 1 classe ;
- 1 subclass ;
- 1 Domain Card ;
- 1 weapon ;
- 1 armor ;
- 1 adversary ;
- 1 environment.

La classe/subclass proviennent du Blood Hunter v1.5, car leurs fichiers complets existent déjà dans `daggerheart-data`. Les autres objets sont prélevés dans les collections SRD 2.0 existantes.

Aucune donnée canonique n'est modifiée.

## 1 — Patch du module

Fusionner le dossier `daggerheart-campaign-toolkit` avec le module déjà installé.

Le module passe en v0.2.0 et ajoute deux compendiums temporaires :

```text
Campaign Toolkit — P2.3.1 Pilot Items
Campaign Toolkit — P2.3.1 Pilot Actors
```

## 2 — Export du pilote depuis DH Data

Depuis :

```text
C:\dev\DH Data
```

lancer :

```bat
python tools\export_foundry_pilot.py "CHEMIN_VERS\FoundryVTT\Data\modules\daggerheart-campaign-toolkit"
```

Le script écrit uniquement :

```text
daggerheart-campaign-toolkit/data/pilot.json
```

## 3 — Reload Foundry

Redémarrer/recharger Foundry, vérifier que le module v0.2.0 est actif.

Dans la console :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.importPilot();
```

Attendu :

```text
pilotItems: 5
pilotActors: 2
```

Puis ouvrir les deux compendiums et vérifier :

- les 5 Items s'ouvrent avec leurs sheets Foundryborne ;
- l'Adversary s'ouvre avec sa sheet native ;
- l'Environment s'ouvre avec sa sheet native ;
- aucune erreur rouge n'apparaît à la création/ouverture ;
- drag & drop d'un Item pilote vers le monde fonctionne.

Pour obtenir le statut :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.pilotStatus();
```

Pour nettoyer le pilote :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.clearPilot();
```

## Stop condition

P2.3.1 est GREEN seulement après validation visuelle et console des documents créés.

Si un type échoue, on corrige uniquement son mapping avant d'étendre le corpus.
