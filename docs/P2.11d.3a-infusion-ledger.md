# P2.11d.3a — Socle des Infusions

Portée : une Infusion par Item possédé par l'Actor Artificier, sans modifier l'Item ni créer de bonus non sourcés. Source d'autorité : flag Actor `daggerheart-campaign-toolkit.artificerInfusions`, contenant les IDs des Items et l'ordre d'infusion ; le compteur est dérivé du registre. Un Item supprimé reste signalé `itemExists:false` pour traitement manuel, et ne libère pas automatiquement une place.

Progression sourcée : niveaux 1/3/5/7/9 → 2/4/6/8/10. On ne crée pas de hook automatique de repos ou de critique avant validation des événements natifs. `clearAtLongRest` nécessite une confirmation explicite. Le registre ne prétend pas accorder de bonus mécaniques.

## Test console après déploiement

```js
const { artificerInfusionApi: inf } = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/artificer-infusion-runtime.mjs?v=${Date.now()}`
);
const actor = canvas.tokens.controlled[0]?.actor;
const eligible = actor?.items.filter(i => ["weapon", "armor", "item", "equipment", "consumable", "loot"].includes(i.type));
console.table(eligible.map(i => ({ id:i.id, name:i.name, type:i.type })));
inf.status(actor);
```

Sélectionner l'ID d'un objet dans la table :

```js
await inf.add(actor, "COLLER_ITEM_ID");
inf.newest(actor);
inf.status(actor);
```

Pour supprimer uniquement l'Infusion de test :

```js
await inf.remove(actor, inf.newest(actor).id);
```

Ne pas appeler `clearAtLongRest` pendant un test de campagne actif. Cette étape ne nécessite aucun réimport des compendiums.
