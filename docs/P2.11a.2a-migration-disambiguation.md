# P2.11a.2a — Désambiguïsation de la migration Chasse

Le premier audit a correctement trouvé les 17 noms, mais a signalé de faux
doublons pour deux raisons :

1. plusieurs cartes possèdent une Action embarquée portant le même nom que la
   carte ; cette Action n'a pas de `domain` et ne doit pas être considérée comme
   une carte ;
2. `Tacticien` existe aussi dans le corpus core (Bone), alors que la carte à
   migrer est celle du homebrew Monster Hunter.

## Correctif

Le migrateur source :
- ne scanne désormais que `data/homebrew/monster-hunter`;
- ne retient qu'un objet nommé qui possède réellement un champ `domain` ou
  `system.domain`.

La migration runtime :
- ne cible une carte par son nom que si sa provenance Toolkit pointe vers
  `data/homebrew/monster-hunter/` ou si son `sourceId` commence par
  `homebrew.monster-hunter.`;
- ne peut donc plus attraper le `Tacticien` core/Bone.
