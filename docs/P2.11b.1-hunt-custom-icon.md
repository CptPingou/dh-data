# P2.11b.1 — Icône custom du domaine Chasse

Asset canonique source :

`assets/icons/domains/hunt.png`

Chemin runtime :

`modules/daggerheart-campaign-toolkit/assets/icons/domains/hunt.png`

Le jalon :
- remplace l'icône temporaire du domaine `hunt` ;
- ajoute `hunt` au catalogue d'icônes des Domain Cards ;
- synchronise la définition Homebrew existante si elle porte encore l'ancien `src` ;
- fournit une migration idempotente pour les cartes Chasse du compendium ;
- met également à jour les Domain Cards `hunt` déjà embarquées sur des Actors.
