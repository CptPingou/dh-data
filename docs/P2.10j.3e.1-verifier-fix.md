# P2.10j.3e.1 — Correction du vérificateur

Le runtime P2.10j.3e utilise :

```js
host.dataset.dhctContainerId = ...
host.dataset.dhctEntryId = ...
```

Le navigateur matérialise cela en attributs HTML :

```html
data-dhct-container-id
data-dhct-entry-id
```

Le vérificateur précédent cherchait à tort la forme HTML littérale dans le
source JavaScript.

Aucun fichier runtime n'est modifié.
