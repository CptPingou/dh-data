# P2.10j.2 — Badges lifecycle sur les objets

Cette étape enrichit la fenêtre `Préparer l’expédition` sans modifier son
renderer interne.

Pour chaque entrée active du manifest, la surcouche cherche le libellé visible
de l'objet puis ajoute un badge compact :

- `Actif`
- `Modifié`
- `Legacy`
- `×N` quand la quantité est supérieure à 1

Les entrées `consumed` et `deleted` ne sont pas annotées : elles sont déjà
dans l'archive et ne font plus partie de `container.contents`.

La logique j.1b de retry/rendu tardif est conservée.
