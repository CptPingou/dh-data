# P1.6 — Multi-corpus integrity audit

P1.6 is the final gate before runtime implementation.

It does not extract new content. It verifies that the corpus assembled in P1
can safely serve as the source model for P2.

The audit checks:

- P1.2, P1.3b, P1.3c, P1.4 and P1.5 are GREEN;
- the SRD/public, private Hope & Fear, playtest, and homebrew layers remain
  physically separated;
- JSON files parse;
- canonical IDs do not collide across entity files;
- private corpora have not leaked into the SRD canonical path;
- primitive evidence counts are internally consistent;
- Monster Hunter still has zero primitive coverage gaps;
- the single-corpus primitive review list is made explicit.

Older extraction/index artifacts that lack full provenance are reported as
warnings rather than rewritten during this gate. P2 can introduce stricter
adapter contracts without mutating the closed source corpus.

## Run

From `C:\dev\DH Data>`:

```bat
python tools\audit_multi_corpus_integrity.py
```

A GREEN result closes **P1 — corpus + primitive discovery** and authorizes:

**P2 — Foundryborne Primitive Module + adapters**.
