# P2.11d.1 — Cob Rounds en ressource native

Le compteur `Cob Rounds [N]` est remplacé par la primitive native `simple`
utilisée par la feature Seaborne **Connaître la marée** dans Foundryborne
2.10.5.

Contrat :
- Feature nommée `Cob Rounds` (plus de `[N]` dans le nom) ;
- `system.resource.type = "simple"` ;
- valeur authoritative : `system.resource.value` ;
- pas de plafond source pour Cob Rounds : `max` natif vide ;
- pas de récupération automatique sur la resource : Battle Rhythm reste
  responsable du gain ;
- le flag historique reste temporairement un miroir de migration ;
- les API `get/set/gain/spend/spendAll` continuent de fonctionner ;
- Battle Rhythm et Frappe décisive gardent leur contrat actuel.

La migration privilégie une Cob resource déjà native. Si l'ancienne feature
pseudo-compteur existe encore, sa valeur historique est migrée depuis le flag.

## Migration runtime

Avec l'Artificier sélectionné :

```js
const api =
  game.modules.get("daggerheart-campaign-toolkit").api.artificerResource;
const actor = canvas.tokens.controlled[0]?.actor;

await api.ensure(actor);
await api.status(actor);
```

Puis inspecter :

```js
const cob = actor.items.find(i =>
  i.flags?.["daggerheart-campaign-toolkit"]?.sourceId ===
  "homebrew.artificer.runtime-resource.cob-rounds"
);

({
  name: cob?.name,
  resource:
    cob?.system?.resource?.toObject?.() ??
    foundry.utils.deepClone(cob?.system?.resource),
  api: await api.get(actor)
});
```

Attendu : `name: "Cob Rounds"`, `resource.type: "simple"`, et la même valeur
dans `resource.value` et `api.value`.
