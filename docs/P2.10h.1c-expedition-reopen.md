# P2.10h.1c — Reload réel de la fenêtre d'expédition

Symptôme après P2.10h.1b :
- manifest correctement sauvegardé ;
- compteur visible mis à jour (ex. 8/8) ;
- grille encore sur l'ancienne liste (ex. 6 items) ;
- fermeture/réouverture manuelle corrige immédiatement la grille.

Conclusion :
`render()` ne recharge pas l'état interne de la fenêtre d'expédition.

Correction :
- après transfert Actor -> backpack :
  1. identifier la fenêtre d'expédition ouverte ;
  2. la fermer ;
  3. la rouvrir via `api.expeditionManifest.open(expeditionId)` ;
- fallback sur `render({force:true})` si l'API `open` n'existe pas.

Ce comportement reproduit automatiquement le chemin manuel déjà validé.
