# P2.10h.2a — Hotfix rollback du wrapper runtime

Le premier essai de P2.10h.2 tentait d'ajouter une propriété Symbol à
`api.expeditionItems`.

Or l'objet API est non extensible, ce qui provoquait une exception dans
le hook `ready` et empêchait l'installation du menu
**Mettre dans le sac à dos**.

Ce hotfix restaure exactement l'état stable P2.10h.1f :

- Actor -> Backpack partiel fonctionnel ;
- quantité 0 refusée ;
- capacité respectée ;
- refresh du dialog fonctionnel ;
- aucun monkey-patch de `api.expeditionItems`.

P2.10h.2 sera repris dans la fonction source `unloadToActor` elle-même.
