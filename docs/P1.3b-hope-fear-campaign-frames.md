# P1.3b — Hope & Fear campaign-frame deep extraction

This phase performs the first private deep extraction after the SRD 2.0 baseline was closed.

It writes one private canonical campaign-frame entity for each Hope & Fear frame:

- Castle High
- Reign of the Weredragon
- Dark Heart of Andaluria
- Journey to Horizon

For each frame the script preserves:

- provenance and printed page range;
- canonical frame sections when found;
- the Campaign Mechanics section;
- conservative structural sub-blocks inside Campaign Mechanics;
- candidate primitive evidence.

The candidate primitives are **not** the final ontology. They are evidence for P1.4.

Private appendix assets are indexed as reference assets only:

- Additional Sheets
- Campaign Frame Maps

No artwork/layout export is performed.

## Run

From the `DH Data` repository root:

```bat
python tools\extract_hope_fear_campaign_frames.py "pdf\Daggerheart_HF.pdf"
```

A GREEN run means all four frames have a detected Campaign Mechanics section and at least one structural mechanic block.
