# P2.10j.3e — Actions dans le panneau de détail droit

Le menu `⋮` est abandonné.

Lorsqu'un objet est cliqué dans `Préparer l’expédition`, la surcouche mémorise
son `containerId` et son `entryId`.

Quand le panneau de détail affiche `Rendre au personnage`, les actions sont
injectées juste après ce contrôle :

- Consommer (consumables uniquement)
- Marquer modifié
- Supprimer

Les actions utilisent exactement les API lifecycle déjà validées en P2.10i.

Aucun menu flottant, popover ou portal n'est conservé.
