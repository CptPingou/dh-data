# P2.11c.1d — Descriptions des cartes Artillery

## Symptôme

Les 9 cartes étaient bien importées (nom, domaine, niveau, Recall, type) mais
leur description était vide dans Foundry.

## Cause

Le corpus Artillery stocke le texte canonique dans :

`raw.rules_text`

Le mapper générique `baseDescription()` ne lisait que :

- `content.rules_text`
- `content`
- `raw.description`

Le texte existait donc bien dans DH-DATA, mais n'était jamais copié dans
`system.description`.

## Correctif

`baseDescription()` accepte maintenant également `raw.rules_text`.

Il s'agit d'un correctif du mapping, pas d'une réécriture des cartes.
