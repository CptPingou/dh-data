# P1.6-fix1 — Canonical ID census

Fixes the false-positive ID collisions from the first P1.6 audit.

The initial audit recursively treated every `id` as a globally canonical ID.
That incorrectly compared canonical outputs with candidate/raw/index/status
artifacts and promoted local nested IDs (campaign-frame sections, evidence
records, etc.) to global identifiers.

Fix1 changes only the auditor:

- intermediate/generated artifacts are excluded from canonical collision checks;
- nested IDs are local and are not promoted globally;
- only top-level entity IDs/direct collection members are collision checked;
- actual duplicate canonical rows remain RED;
- corpus boundaries, JSON parsing, primitive integrity and previous phase gates
  remain unchanged.

No extracted data is modified.

Run:

```bat
python tools\audit_multi_corpus_integrity.py
```
