# P1.1c — Equipment + Beastforms extractor

À fusionner dans `daggerheart-data/`.

Exécution depuis la racine de la base :

```bat
python tools\extract_srd2_equipment.py "C:\dev\DH Data\pdf\DH_SRD_2_2026_08_25.pdf"
```

Le script traite quatre collections avec un garde-fou quantitatif strict :

- Armor : 68
- Items : 120 = 60 Core + 60 Hope & Fear
- Consumables : 120 = 60 Core + 60 Hope & Fear
- Beastforms : 24 = 6 par tier

Il extrait également les armes dans `weapons-raw.json`, mais celles-ci restent
`canonical: false` pendant cette passe. Les tables d'armes sont plus complexes
(tiers, Primary/Secondary, sous-groupes Physical/Magic, armes additionnelles et
matériel de campagnes supplémentaires) ; elles auront leur gate propre en P1.1d.

## Gate

On veut :

```json
"canonical_collections_validation": "GREEN"
```

Si le script retourne RED, ne corrige pas les JSON manuellement : envoie la
sortie console. On corrigera le parseur puis on relancera depuis le PDF source.
