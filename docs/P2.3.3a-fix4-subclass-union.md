# P2.3.3a fix4 — union canonique des sous-classes SRD

Audit réalisé sur le ZIP réel `DH Data.zip` fourni le 2026-09-03.

## Cause du RED fix3

`data/srd-2.0/indexes/subclasses.json` contient 22 entrées.
`data/srd-2.0/indexes/subclasses-hope-fear.json` contient 8 entrées.
Quatre entrées H&F sont déjà présentes dans `subclasses.json` et quatre sont supplémentaires :

- Pact of the Endless — Warlock
- Pact of the Wrathful — Warlock
- Hedge — Witch
- Moon — Witch

L'union par ID stable donne donc 26 sous-classes SRD, conformément à `data/srd-2.0/registry/P1.2-status.json`.

Avec les 3 sous-classes Blood Hunter v1.5, l'import doit produire 29 sous-classes.

## Correction

Le manifest canonique référence désormais les deux index SRD. L'exporteur existant déduplique déjà les entités par `(kind, id)`, donc les quatre entrées communes ne sont importées qu'une fois.

Aucun changement de données source et aucun filtrage ad hoc.
