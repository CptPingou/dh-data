# P2.10j.3g — Boutons natifs dans la colonne Objet

Structure visée :

1. Inventaire
2. WEB / FOUNDRY / Journal
3. Conteneurs | Contenu | Objet
4. Fermer

Dans la colonne `Objet`, les actions sont injectées directement dans le même
parent DOM que `Rendre au personnage`.

Ordre :

- Rendre au personnage
- Consommer
- Marquer modifié
- Supprimer

Aucun conteneur transversal supplémentaire n'est créé.

Chaque bouton recopie `className` du bouton natif `Rendre au personnage`, puis
ajoute seulement la classe technique `dhct-right-item-action`.

Les actions rechargent toujours le manifest frais avant exécution.
