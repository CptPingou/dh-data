# P2.11c.6b1 — Hotfix `decisiveStrikeStatus`

P2.11c.6b contenait une erreur de nom de fonction dans le diagnostic :

```js
findCounterFeature(actor)
```

alors que le helper existant du runtime s'appelle :

```js
counterFeature(actor)
```

Ce hotfix corrige uniquement ce point. Il ne change pas la mécanique de
Frappe décisive.

## Vérification

```powershell
cd C:\dev\dh-data
powershell -ExecutionPolicy Bypass `
  -File ".\tools\verify-p2.11c.6b1.ps1"
```
