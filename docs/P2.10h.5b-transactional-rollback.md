# P2.10h.5b — Rollback transactionnel

Actor -> Backpack est protégé au niveau de l'action de menu existante,
autour de `api.expeditionItems.loadFromActor(...)`.

Backpack -> Actor reste protégé directement dans `unloadToActor()`.

Avant mutation, on capture :
- le manifest ;
- l'inventaire complet de l'Actor.

En cas d'exception :
- restauration du manifest ;
- restauration de l'inventaire Actor ;
- propagation de l'erreur d'origine.
