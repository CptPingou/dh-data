# P2.11c.8 — Synchronisation des cartes Artillery possédées

Objectif : après un nouvel import Artificier + Artillery, les cartes déjà
possédées par les PJ ne doivent plus rester sur une ancienne version.

## Contrat

`syncOwnedArtilleryCards()` :

- parcourt tous les Actors du monde ;
- identifie uniquement les cartes dont le `sourceId` est
  `homebrew.artificer.domain-card.artillery.*` ;
- prend le compendium Toolkit comme source de vérité ;
- synchronise nom, icône, système, actions, flags et ActiveEffects ;
- conserve les compteurs `uses.value` déjà consommés sur l'Actor ;
- conserve la valeur d'une éventuelle resource native ;
- conserve les principaux états de placement/loadout de la copie possédée ;
- n'intervient pas sur les autres cartes ou Items.

`importArtificerArtillery()` lance désormais cette synchronisation
automatiquement juste après la reconstruction des 9 cartes.

## Test runtime

```js
const hb = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/pilot-import.mjs?v=${Date.now()}`
);

const result = await hb.importArtificerArtillery();
result.ownedCards;
```

Attendu :

```text
green: true
cardsFound: <nombre de cartes Artillery possédées>
cardsUpdated: même nombre
missing: []
```

La fonction peut également être appelée seule :

```js
await hb.syncOwnedArtilleryCards();
```
