# P2.10h.1 — Quantité partielle Actor → backpack

## Comportement

Pour un item unitaire :
- transfert normal ;
- suppression de l'Item sur l'Actor après sauvegarde du manifest.

Pour un stack :
- demande de quantité ;
- `loadFromActor()` reçoit uniquement la quantité choisie ;
- si quantité < disponible, l'Item reste sur l'Actor avec la quantité restante ;
- si quantité = disponible, l'Item est supprimé ;
- si le débit Actor échoue après sauvegarde du manifest, le manifest est restauré.

Formats supportés :
- `system.quantity`
- `system.quantity.value`
- `system.amount`
- `system.amount.value`

## Hors scope P2.10h.1

- fusion de stacks dans le backpack ;
- fusion lors du retour Actor ;
- retour partiel depuis le backpack.
