# P2.10j.1 — Synthèse UX inventaire

Cette étape ajoute une surcouche DOM isolée au dialogue
`Préparer l’expédition`.

Elle n'altère pas le renderer du manifest.

Le panneau affiche :

- Actifs
- Modifiés
- Legacy
- Archivés
- Bloqués restitution

Les données viennent exclusivement de :

```js
api.expeditionItems.scanLifecycle(manifest)
api.expeditionItems.restitutionStatus(manifest)
```

Le panneau est rafraîchi :

- à l'ouverture du dialogue ;
- après le hook `daggerheart-campaign-toolkit.expeditionChanged`.

`apply_p2_10j_1_main.py` branche le module UX dans `scripts/main.mjs`.
