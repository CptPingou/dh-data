# P2.10j.4d — Hauteur native, footer bas, rangées de slots

Corrections basées sur le DOM réel.

## Hauteur

La hauteur native du dialog est mémorisée à la première passe puis la fenêtre
est portée à `hauteur native × 1,10`, avec garde-fou à 94 % du viewport.

L'ancienne hauteur fixe `92vh` est supprimée.

## Footer

La chaîne flex est appliquée sur :

- `.window-content`
- `.dialog-form`
- `.dialog-content`
- `.dct-expedition-window`

Le bloc `Fermer` conserve `margin-top:auto`, ce qui le repousse réellement
au bas de la fenêtre.

## Grille

Le renderer natif utilise :

```css
grid-auto-rows: 82px;
```

Cette hauteur est insuffisante pour image + nom + badge.

Le toolkit impose maintenant :

```css
grid-auto-rows: 128px;
row-gap: .85rem;
```

Les noms peuvent revenir à la ligne sans empiéter sur la rangée suivante.
