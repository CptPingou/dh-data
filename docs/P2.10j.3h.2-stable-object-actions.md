# P2.10j.3h.2 — Stabilisation des actions Objet

Cause du non-fonctionnement :

L'injection des boutons déclenchait le `MutationObserver`, qui relançait le
refresh, supprimait/recréait les boutons et déclenchait de nouveau
l'observer. Les boutons étaient donc continuellement remplacés.

Correction :

- l'injection devient idempotente pour un même `containerId + entryId`;
- les boutons stockent leur sélection dans `data-container-id/data-entry-id`;
- l'observer ignore les mutations ne concernant que
  `[data-dhct-inventory-action]`;
- les listeners click sont attachés en capture.

Le placement exact dans `.dct-expedition-item-actions` est inchangé.
