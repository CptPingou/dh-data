# P2.10g — Bootstrap d'expédition par World

Objectif : un nouveau World Foundry ne doit plus nécessiter de construction manuelle du manifest.

Au `ready`, pour le MJ :
- réutilise le manifest actif s'il existe ;
- sinon crée `world-<worldId>` ;
- détecte tous les Actors `character` ;
- crée/actualise une entrée `characters[]` par PJ ;
- crée/actualise un backpack personnel par PJ ;
- lie `holderRef.foundryActorUuid` ;
- initialise 8 slots, `rules: []`, `contents: []` ;
- valide le manifest puis sauvegarde uniquement si nécessaire.

API runtime :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;

await api.expeditionWorld.status();
await api.expeditionWorld.bootstrap({ notify: true });
```

Le bootstrap est idempotent : un second passage ne duplique ni personnages ni sacs.
