# P2.10i.4 — Plan de restitution

Cette étape prépare la fin d'expédition sans encore modifier les Actors.

## États restituables

- active
- modified
- legacy

## États non restitués

Les entrées terminales ont déjà été archivées :

- consumed
- deleted

Elles apparaissent dans `archiveAudit` uniquement.

## API

```js
api.expeditionItems.restitutionPlan(manifest)
api.expeditionItems.restitutionStatus(manifest)
```

Le plan contient :

- `returnItems`
- `blockedItems`
- `archiveAudit`
- `summary`

## Blocages détectés

Une entrée active est bloquée si :

- son container n'est relié à aucun Actor Foundry ;
- sa quantité est invalide ;
- elle n'a ni snapshot ni UUID source exploitable comme indice de résolution.

Aucune restitution n'est exécutée dans P2.10i.4.
