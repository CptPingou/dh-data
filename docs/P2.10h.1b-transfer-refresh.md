# P2.10h.1b — Validation quantité + refresh expédition

Corrections après test de P2.10h.1 :

- quantité `0` : transfert refusé avec notification ;
- quantité > stock : reste bornée au stock disponible ;
- fenêtre d'expédition ouverte : rerender après transfert réussi ;
- plusieurs transferts identiques restent séparés jusqu'à P2.10h.3 ;
- blocage capacité/slots reste géré par le manifest.

Le refresh balaie les applications ouvertes dont le nom de classe ou l'id
contient `expedition`, compatible avec les applications v1/v2 de Foundry.
