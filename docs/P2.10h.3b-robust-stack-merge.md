# P2.10h.3b — Stack merge, patcher robuste

Le premier patch h.3 pouvait appliquer la partie Backpack puis s'arrêter
sur la partie Actor parce qu'il recherchait un bloc texte exact.

Cette version :

- détecte la fusion Backpack déjà présente et ne la duplique pas ;
- cible la séquence `createEmbeddedDocuments -> extract -> rollback`
  avec une regex structurelle ;
- modifie le retour de `unloadToActor` pour exposer `mergedItemId` ;
- reste idempotente.

Elle peut donc être appliquée directement après l'échec du premier h.3.
