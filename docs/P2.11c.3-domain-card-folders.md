# P2.11c.3 — Dossiers de domaine dans dh-domain-cards

## But

Classer toutes les cartes du compendium Toolkit :

`daggerheart-campaign-toolkit.dh-domain-cards`

dans un sous-dossier correspondant à `system.domain`.

Le classement couvre donc automatiquement les domaines core et les domaines
homebrew présents dans le pack, notamment `hunt` et `artillery`.

## Principe

- un dossier Item est créé par domaine ;
- le dossier reçoit le flag Toolkit `domainCardFolder`;
- les dossiers existants portant déjà le bon nom sont adoptés au lieu d'être dupliqués ;
- chaque carte est déplacée vers le dossier correspondant à `system.domain`;
- une seconde exécution est idempotente.

Les cartes sans `system.domain` ne sont pas déplacées et sont signalées dans
`unclassified`.

## Exécution indépendante

```js
const hb = await import(
  `/modules/daggerheart-campaign-toolkit/scripts/pilot-import.mjs?v=${Date.now()}`
);

await hb.organizeDomainCardsByDomain();
await hb.domainCardFolderStatus();
```

Cible :

`green: true`

`changed` indique combien de cartes ont été déplacées lors de l'exécution.

Une seconde exécution doit normalement retourner `changed: 0`.
