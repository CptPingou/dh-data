# P2.10g.3c — Artwork matcher hardening

Améliorations après le dry-run 3b :

- normalisation des possessifs :
  - `Alistair's Torch` -> `alistair-s-torch`
- matching par préfixe canonique :
  - `minor-health-potion-clear-1d4` -> `minor-health-potion`
- doublons de noms autorisés uniquement si toutes les entrées natives
  correspondantes utilisent exactement la même image :
  - plusieurs `Revolver`
  - plusieurs `Lasso`
  - etc.

Aucun fuzzy matching n'est utilisé.

Le script reste conservateur :
si plusieurs candidats possibles ont des images différentes, l'entrée reste
`unmatched`.
