# P2.3.3a — audit d'identité SRD

Micro-étape de diagnostic. Aucun import Foundry et aucune donnée canonique ne sont modifiés.

Le script inspecte uniquement `data/srd-2.0` pour `domain_card` et `adversary` et produit :
- comptes par fichier source ;
- occurrences brutes et IDs uniques ;
- collisions d'ID ;
- collisions de nom avec IDs différents ;
- fichiers potentiellement techniques (`raw`, `index`, `candidate`, `audit`, etc.) ;
- inventaire complet ID / nom / fichier source.

Exécution depuis `C:\dev\DH Data` :

```bat
python tools\audit_foundry_full_identity.py
```

Le rapport détaillé est écrit dans `docs/audits/P2.3.3a-identity-audit.json`.
