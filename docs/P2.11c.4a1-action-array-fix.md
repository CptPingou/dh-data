# P2.11c.4a1 — Correctif sérialisation des Actions Artillery

## Symptôme

Le status indiquait les bons flags d'automatisation mais `actions: 0` pour les
trois cartes.

## Cause

Le mapper injectait `system.actions` sous forme d'objet indexé par `_id`.

Le JSON exporté par Foundry peut bien **apparaître** sous cette forme, mais le
modèle source de Foundryborne 2.9.4 attend un **tableau** lors de `Item.create()`.

Le schéma nettoyait donc silencieusement l'objet et créait les cartes sans Action.

## Correctif

Les actions sont maintenant injectées via :

```js
data.system.actions = Object.values(actionMap);
```

Le status runtime sait également lire les différentes représentations possibles
(Array, Collection, Map ou objet sérialisé).
