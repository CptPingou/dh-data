# P2.10j.3 — Actions contextuelles d'inventaire

Dernière étape fonctionnelle de P2.10j avant retouche visuelle.

Chaque objet actif du panneau reçoit un bouton `⋮`.

Actions :

- `Consommer`
  - disponible uniquement pour les `consumable`
  - demande une quantité si la pile > 1
  - utilise `api.expeditionItems.consume`
  - archive automatiquement l'entrée si elle devient terminale

- `Marquer modifié`
  - confirmation
  - utilise `api.expeditionItems.setLifecycle(... state: "modified")`
  - ne change pas le snapshot mécanique

- `Supprimer`
  - confirmation
  - utilise `api.expeditionItems.delete`
  - archive immédiatement l'entrée terminale

Après chaque action :
- manifest sauvegardé
- hook `expeditionChanged`
- dialogue fermé puis rouvert avec les données fraîches
