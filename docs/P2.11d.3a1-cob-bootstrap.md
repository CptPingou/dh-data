# P2.11d.3a1 — Cob bootstrap neuf

Le hook createItem Artificier (P2.11d.1) demandait une feature simple déjà portée par un Actor. Sur un monde où aucun Actor ne possède ce compteur, l’import d’une nouvelle classe Artificier échouait à créer Cob Rounds.

Ce correctif cherche désormais un specimen simple dans le compendium Toolkit dh-features. Si aucun n’y existe, un seed minimal du schéma simple déjà observé est utilisé. Le Cob natif reste autoritatif; l’ancien flag reste un miroir de migration. Aucun changement dans le ledger d’Infusions P2.11d.3a.

Le problème `ItemBrowser._onDragStart / setDragImage` vient du module système Daggerheart 2.10.6; il est indépendant du bootstrap Cob et n’est pas patché ici.
