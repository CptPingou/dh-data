# P2.11c.5b — Rythme de bataille complet + icône Cob Rounds

## Correction de règle

La source Artillery dit :

- sur une réussite critique d'attaque : **effacer 1 Stress** ;
- une fois par repos, pendant un moment de calme entre deux vagues :
  **effacer 2 Stress et placer 1 Cob Round / jeton de charge**.

Le prototype précédent ajoutait par erreur le Cob Round sur le critique.
P2.11c.5b corrige cette interprétation.

## Runtime

### Critique d'attaque

Le hook `dualityRoll`, déjà validé en P2.11c.5a :

```text
critique + Artificier + Rythme de bataille
→ efface automatiquement 1 Stress
```

Aucun Cob Round n'est généré par le critique.

### Moment de calme

`Rythme de bataille` reçoit une Action Foundryborne native :

```text
Moment de calme
1 / repos
→ efface 2 Stress
→ le runtime ajoute 1 Cob Round
```

Le nettoyage de Stress est porté par l'Action native ; le compteur Cob Round
reste sous autorité du Toolkit.

## Cob Rounds

La feature runtime utilise maintenant l'asset existant :

```text
modules/daggerheart-campaign-toolkit/assets/icons/domains/artillery.png
```

Elle reçoit également son propre `sourceId` au lieu de conserver la provenance
du specimen utilisé lors de sa création.
