# P2.11c.6b — Détection réelle de l’Action Frappe décisive

Le runtime réel montre que `Armer Frappe décisive` produit :

```text
type: abilityUse
system.title: undefined
system.source.item: <id de Frappe décisive>
system.source.action: <id de l'Action>
```

Le détecteur 6a exigeait un titre contenant `Frappe décisive`, donc il ignorait
ce message.

P2.11c.6b reconnaît désormais l'Action par :

1. `system.source.item` -> carte possédée ;
2. `sourceId` de cette carte =
   `homebrew.artificer.domain-card.artillery.decisive-strike`;
3. `message.type === "abilityUse"`.

Aucune heuristique textuelle n'est nécessaire dans ce chemin.
