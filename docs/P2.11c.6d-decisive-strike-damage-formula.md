# P2.11c.6d — Frappe décisive : formule native de dégâts

Le test 6c montre que `preDamageAction` reçoit bien `extraFormula: 4d6`,
mais Foundryborne 2.10.5 ne l'intègre pas au DamageRoll. Le dégât normal de
la Baguette reste `@profd6+1` (soit `4d6+1` avec Prof 4).

P2.11c.6d modifie temporairement la formule native de l'Action :

`(@profd6+1) + 4d6`

puis restaure la formule d'origine dès que le DamageRoll est créé.
