# P2.10f.2a — Panneau objet à droite

Le détail de l'objet sélectionné n'est plus affiché sous la grille.

La fenêtre est organisée en trois colonnes :
1. conteneurs ;
2. contenu/grille ;
3. objet sélectionné + actions contextuelles.

Le panneau objet reste fixe dans la colonne de droite pendant l'utilisation de la grille.
Sous une largeur de 980 px, il bascule sous la colonne de contenu pour éviter l'écrasement.

Aucune logique métier n'est modifiée.

Versions :
- Toolkit `0.5.59`
- Expedition Window `14`
