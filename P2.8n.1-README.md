# P2.8n.1 — Domaine virtuel Chasse : présentation

Patch-only sur P2.8n GREEN.

## Décision
Les cartes Chasse restent techniquement des `domainCard` Foundryborne avec
`system.domain = "valor"` pour ne pas casser l'hydratation/validation native.

**Valor n'est plus leur domaine sémantique.**
La source de vérité fonctionnelle est :

```js
flags["daggerheart-campaign-toolkit"].toolkitCard = {
  family: "hunt",
  familyLabel: "Chasse",
  eligibility: "toolkit",
  loadoutGroup: "hunt"
}
```

## Patch
Ajoute un bridge de présentation qui :
- détecte toute Toolkit Card via `toolkitCard.family`;
- affiche `familyLabel` (`Chasse`) sur sa fiche à la place du libellé natif trompeur;
- ne modifie jamais `system.domain`;
- reste générique pour les futures familles Dragonmark / House / etc.

## Test console
```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
api.toolkitCardPresentation.status();
```

Attendu :
```js
{
  green: true,
  semanticFamily: "hunt",
  displayLabel: "Chasse",
  nativeDomainPreserved: "valor"
}
```

Puis ouvrir une carte Chasse : le libellé visible doit être `Chasse`, tandis que
`card.system.domain` reste `valor`.
