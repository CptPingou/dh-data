# P2.8o.2 — Verrou complet du cycle d'Engagement

Patch-only au-dessus de P2.8o.1.

## Ce que verrouille cette étape

- Un **Opener** n'est accepté que lorsqu'aucun Engagement n'est ouvert.
- Un second Opener ne peut plus réinitialiser `participants` et contourner le budget d'Action MH.
- Un **Support** n'est accepté que pendant un Engagement ouvert.
- Un **Finisher** n'est accepté que pendant un Engagement ouvert.
- Chaque Actor ne peut recevoir qu'une seule résolution Monster Hunter (`opener`, `support` ou `finisher`) dans la fenêtre courante.
- Après le Finisher, l'Engagement est fermé comme avant.
- Le prochain Opener ouvre une nouvelle fenêtre et remet les budgets à zéro.
- Si l'Opener ne peut pas payer ses 2 Hope, l'état nouvellement ouvert est annulé pour éviter un Engagement fantôme.

## Important

Le verrou porte sur la **résolution Monster Hunter**. Foundryborne peut avoir déjà lancé/affiché
l'action native avant que le hook Toolkit la refuse. L'interception pré-roll/UI pourra être ajoutée
plus tard si elle devient nécessaire.

## Test recommandé

1. Opener `test` → accepté.
2. Support `test2` → accepté.
3. Deuxième Support `test2` → refusé, aucun nouveau coût/effet Toolkit.
4. Finisher par le Finisher désigné → accepté, Opportunity remise à 0, Engagement fermé.
5. Nouvel Opener → accepté ; `participants` repart sur une nouvelle fenêtre.
